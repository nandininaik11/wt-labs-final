📖 How Canvas Works

The <canvas> tag is an HTML5 element that provides a drawable region. JavaScript gets a 2D rendering context via canvas.getContext('2d'). Drawing is done by calling methods like beginPath(), moveTo(), lineTo(), rect(), arc(), stroke(), fill(). Mouse events (mousedown, mousemove, mouseup) track user interaction. A second transparent preview canvas sits on top and shows a live preview while dragging.
