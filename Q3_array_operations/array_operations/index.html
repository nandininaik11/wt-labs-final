↩️ Reverse Array
Theory: Reversing an array means placing the last element first, second-last second, and so on. Method 1: Use built-in array.reverse() — mutates original. Method 2: Manual swap using a two-pointer technique — swap arr[0]↔arr[n-1], arr[1]↔arr[n-2], until middle.

// Method 1: Built-in reverse() — modifies original array function reverseBuiltIn(arr) { return [...arr].reverse(); // spread to avoid mutating original } // Method 2: Manual two-pointer swap function reverseManual(arr) { let result = [...arr]; // copy array let left = 0; let right = result.length - 1; while (left < right) { // until pointers meet // Swap elements at left and right [result[left], result[right]] = [result[right], result[left]]; left++; // move left pointer right right--; // move right pointer left } return result; }
🫧 Bubble Sort
Theory: Compares adjacent pairs and swaps if they're in the wrong order. After each pass, the largest unsorted element "bubbles up" to its correct position.
Best case: O(n) — already sorted | Average/Worst: O(n²)

O(n²)

📄 View JavaScript Code
function bubbleSort(arr) { let n = arr.length; let steps = 0, swaps = 0; for (let i = 0; i < n - 1; i++) { let swapped = false; // optimization flag for (let j = 0; j < n - i - 1; j++) { steps++; if (arr[j] > arr[j + 1]) { // Swap adjacent elements [arr[j], arr[j+1]] = [arr[j+1], arr[j]]; swapped = true; swaps++; } } // If no swap in entire pass → already sorted if (!swapped) break; } return { arr, steps, swaps }; }
🎯 Selection Sort
Theory: Finds the minimum element in the unsorted portion and places it at the beginning. After each pass, the sorted portion grows by one.
Time: Always O(n²) — never better, never worse.
Time (All)
O(n²)
Space
O(1)
Stable
❌ No
Swaps
O(n)
Passes: 0  |  Comparisons: 0

📄 View JavaScript Code
function selectionSort(arr) { let n = arr.length; let comparisons = 0; for (let i = 0; i < n - 1; i++) { let minIdx = i; // assume first unsorted is minimum // Find actual minimum in rest of array for (let j = i + 1; j < n; j++) { comparisons++; if (arr[j] < arr[minIdx]) { minIdx = j; // update min index } } // Swap minimum to correct position if (minIdx !== i) { [arr[i], arr[minIdx]] = [arr[minIdx], arr[i]]; } } return { arr, comparisons }; }
📌 Insertion Sort
Theory: Like sorting playing cards — pick one card at a time and insert it into its correct position in the already-sorted portion.
Best case: O(n) for nearly-sorted arrays. Efficient for small arrays.
Time (Best)
O(n)
Time (Worst)
O(n²)
Space
O(1)
Stable
✅ Yes
Passes: 0  |  Shifts: 0

📄 View JavaScript Code
function insertionSort(arr) { let n = arr.length; let shifts = 0; for (let i = 1; i < n; i++) { let key = arr[i]; // element to be inserted let j = i - 1; // start comparing with left neighbor // Shift larger elements one position right while (j >= 0 && arr[j] > key) { arr[j + 1] = arr[j]; // shift right j--; shifts++; } arr[j + 1] = key; // insert key at correct position } return { arr, shifts }; }
⚡ JavaScript Built-in .sort()
Theory: JavaScript's built-in Array.prototype.sort() method. Without a comparator, it converts elements to strings (causes wrong numeric order!). Always pass a comparator function: arr.sort((a, b) => a - b) for ascending.

🔍 Linear Search
Theory: Checks each element one by one from left to right until the target is found or the array ends. Works on unsorted arrays. Simple but slow for large arrays.
Best case: O(1) — element at first position | Worst: O(n) — last position or not found.
Time (Best)
O(1)
Time (Worst)
O(n)

Not needed
Comparisons made: 0

function linearSearch(arr, target) { for (let i = 0; i < arr.length; i++) { if (arr[i] === target) { return i; // return index where found } } return -1; // return -1 if not found (convention) } // Usage: const arr = [15, 4, 8, 22, 11]; const idx = linearSearch(arr, 11); // → 4 (index) const idx2 = linearSearch(arr, 99); // → -1 (not found) // Built-in equivalents: arr.indexOf(11); // → 4 arr.includes(11); // → true arr.find(x => x === 11); // → 11 (value)
🎯 Binary Search
Theory: Works ONLY on sorted arrays. Like finding a word in a dictionary — open in the middle, decide left or right half, repeat. Each step eliminates HALF the remaining elements → very fast for large arrays.
n=1000 elements: Linear needs up to 1000 steps, Binary needs only ~10!
Time (Best)
O(1)
Time (Worst)
O(log n)
Sorted?
✅ Required
Iterations: 0  |  O(log n) = 0
Array must be sorted. Binary search works by halving the search space each step.
📄 View JavaScript Code
function binarySearch(arr, target) { let left = 0; let right = arr.length - 1; let steps = 0; while (left <= right) { steps++; // Find middle index (avoid overflow vs (left+right)/2) let mid = Math.floor((left + right) / 2); if (arr[mid] === target) { return { index: mid, steps }; // found! } else if (arr[mid] < target) { left = mid + 1; // search RIGHT half } else { right = mid - 1; // search LEFT half } } return { index: -1, steps }; // not found }
