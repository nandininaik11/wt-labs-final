Task 2 Your Stored BCrypt Hash

This is what is stored in the database — never the plain password:

$2a$10$...
BCrypt hash format: $2a$10$[22-char salt][31-char hash]
Task 1 BCrypt Password Encoder — How It Works
1. CONFIGURE
new BCryptPasswordEncoder(10)
Strength 10 = 2^10 = 1024 hashing rounds
2. ENCODE
encoder.encode("plain")
Generates random salt + hash → stores in DB
3. AUTHENTICATE
Spring Security loads user from DB
Compares hash using BCrypt
4. VERIFY
encoder.matches(raw, hash)
Returns true/false → login success/fail
