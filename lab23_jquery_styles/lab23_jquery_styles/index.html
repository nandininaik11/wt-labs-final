📖 About This Page

jQuery Dynamic Styling

This page demonstrates how jQuery can apply a single consistent style across ALL page controls — headings, paragraphs, inputs, select dropdowns, textareas, tables, buttons, and lists — using just three buttons. Each button applies a completely different theme to the entire page.

jQuery's $('body').removeClass().addClass() removes the old theme class and adds the new one. Since all elements inherit from body, the entire page instantly re-styles.
