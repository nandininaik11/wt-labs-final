🔌 REST API Reference

Task Manager REST API — Lab Question 35 | Base URL: http://localhost:3000

Method
Endpoint
Description
GET
/api/tasks
Retrieve all tasks (supports ?status, ?priority, ?search)
GET
/api/tasks/:id
Get one task by ID
POST
/api/tasks
Create a new task
PATCH
/api/tasks/:id
Update task (status, title, priority, etc.)
DELETE
/api/tasks/:id
Delete a single task by ID
DELETE
/api/tasks/completed/all
Delete all completed tasks
GET
/api/stats
Get task statistics & counts
Example: GET /api/tasks Response (JSON)
{ "success": true, "count": 5, "stats": { "total": 5, "pending": 3, "completed": 2 }, "tasks": [ { "id": "a1b2c3d4-e5f6-...", "title": "Complete WT Lab", "description": "Finish all lab questions", "status": "pending", "priority": "high", "category": "Study", "createdAt": "2025-01-01T10:00:00.000Z", "updatedAt": "2025-01-01T10:00:00.000Z" } ] }

{ "title": "Study React Hooks", "description": "Learn useState, useEffect", "priority": "high", "category": "Study" }
