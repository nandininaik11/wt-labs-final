VIT Project-Based Learning

Understanding the Relevance of SDP, EDI, DT, and Course Projects

Skill Development Project (SDP)

SDPs enhance employability through hands-on training.

Relevance: Bridges academic learning and industry needs.
Assessment Schema
Continuous Assessment50
Project Demonstration30
Viva Voce20
Total100
Sample SDP Project

Project: Student Attendance Management System

A web-based system to automate attendance and report generation.
How to Write for Assessment
  • Mention weekly progress and tools learned for continuous assessment.
  • Explain live working of the system during demonstration.
  • Justify design and future scope in viva.

Engineering Design and Innovation (EDI)

EDI focuses on innovative problem-solving and product design.

Relevance: Encourages entrepreneurship and societal solutions.
Assessment Schema
Problem Identification20
Design & Innovation30
Prototype30
Presentation & Viva20
Total100
Sample EDI Project

Project: Smart Waste Segregation System

An IoT-based solution to segregate wet and dry waste.
How to Write for Assessment
  • Clearly explain the real-world problem.
  • Highlight innovation and feasibility.
  • Show working prototype or simulation.
  • Explain business and social impact.

Design Thinking (DT)

In DT we do research work. It could be writting book chapters, journal paper, magazine, participating in conferences .

Relevance: Focuses on user needs and creative thinking.
Assessment Schema
Empathize & Define25
Ideation25
Prototype & Testing30
Documentation & Viva20
Total100
Sample DT Project

Project: Hospital Appointment Booking System

A system designed after patient interviews to reduce waiting time.
How to Write for Assessment
  • Explain user interviews and pain points.
  • Define the core problem clearly.
  • Describe ideation and prototype testing.

Course-Based Projects

Course projects apply subject concepts practically.

Relevance: Strengthens understanding of core subjects.
Assessment Schema
Implementation40
Continuous Evaluation20
Report20
Viva20
Total100
Sample Course Project

Project: Library Management System (DBMS)

Implements ER diagrams, SQL queries, and normalization.
How to Write for Assessment
  • Explain how theory concepts are implemented.
  • Mention regular reviews and improvements.
  • Justify design decisions in viva.
